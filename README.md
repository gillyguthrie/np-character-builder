# Nerevarine Prophecies Character Builder

https://gillyguthrie.github.io/np-character-builder/

A community loadout planner for the Nerevarine Prophecies TES3MP server.

Pick a race, birthsign, and specialization, equip server items, toggle masteries, and see computed Health, Magicka, Fatigue, Armor Rating, resists, and DPS. Every tile and resist row has a click-to-open breakdown showing exactly where each number comes from.

Loadouts save to small `.json` files you can share and load back in.

Built by and for the NP community. Item data comes from the server-items Discord channel and Skooma Breath's extensive item list. Report errors or missing items on the server Discord.
